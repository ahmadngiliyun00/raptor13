# Bantuan

- **Pertanyaan cara bermain atau memasang aplikasi.** Buka Discussions di repo, atau issue dengan templat
  Pertanyaan.
- **Bug.** Buka issue dengan templat Laporan bug. Sertakan info diagnostik dari tombol Lapor Bug di menu Jeda,
  atau dari `index.html?diag=1`.
- **Masalah keamanan.** Ikuti `SECURITY.md`. Jangan laporkan lewat issue publik.
- **Ingin ikut mengembangkan.** Baca `CONTRIBUTING.md`, lalu cari issue berlabel `good first issue`.

Proyek ini dikelola sukarela, jadi jawaban bisa memakan beberapa hari.
