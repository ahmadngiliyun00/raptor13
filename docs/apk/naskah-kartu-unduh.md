# Naskah kartu unduh APK (D6, belum diimplementasikan)

Kartu kecil di menu utama atau layar Credits. Hanya tampil di Android, dan tidak tampil di dalam aplikasi atau
PWA yang sudah terpasang.

**Judul:** Main layar penuh di aplikasi Android

**Isi:**
RAPTOR13 juga tersedia sebagai aplikasi Android (APK, sekitar {UKURAN} MB, versi {VERSI}). Aplikasi ini
dibagikan langsung dari situs resmi dan GitHub proyek, bukan dari Google Play Store.

**Tombol:** Unduh | Nanti | [ ] Jangan tampilkan lagi

**Panel "Sebelum memasang" (muncul setelah Unduh):**

1. Unduh hanya dari raptor13.ngiliyun.my.id atau halaman GitHub Releases proyek ini.
2. Android akan meminta izin "Pasang aplikasi tidak dikenal" untuk browser Anda. Izinkan sekali, lalu matikan
   lagi setelah selesai.
3. Google Play Protect bisa menampilkan peringatan karena aplikasi ini tidak berasal dari Play Store. Itu wajar
   untuk APK di luar Play Store. Lanjutkan hanya bila berkas berasal dari tautan resmi.
4. Verifikasi (opsional): sidik jari SHA-256 sertifikat penandatanganan adalah `{SIDIK_JARI}`, dan checksum
   berkas ada di SHA256SUMS pada halaman rilis.
5. Kebijakan verifikasi developer Android sedang berubah (perluasan global direncanakan 2027). Bila suatu
   saat HP Anda menolak memasang, gunakan versi web di browser sambil menunggu pembaruan.

**Yang tidak boleh diklaim:**

- bahwa aplikasi lebih cepat dari browser (mesinnya sama);
- bahwa aplikasi "aman dari Google" atau "terverifikasi Google" sebelum pendaftaran nama paket benar-benar
  selesai;
- bahwa Play Protect tidak akan memperingatkan.
