# Peta jalan RAPTOR13

Rencana ini dapat berubah. Area yang ditandai **butuh bantuan** terbuka untuk kontributor. Lihat issue
berlabel `help wanted` dan `good first issue`.

## Sedang dikerjakan

- Robot Piko bergerak mandiri dan menempel ke kapal.
- Senjata bertingkat berbasis titik pasang (hardpoint).
- Kehalusan penerbangan.
- Manuver Putar Balik U.
- Aplikasi Android (APK) dan rilis otomatis lewat GitHub Actions.
- Proyek iOS (Capacitor) dan panduan pemasangan.

## Direncanakan

- Keseimbangan Sang Naga Vanta: generator perisai lebih mudah dibidik (butuh keputusan desain).
- Kapal baru dengan peran berbeda, dan peralatan tambahan (Drone Pendamping sebagai peralatan).
- Mode luring penuh lewat service worker (PWA).

## Butuh bantuan

| Area | Contoh pekerjaan |
| --- | --- |
| Kapal dan peralatan | Usulan kapal atau peralatan orisinal lengkap dengan angka keseimbangan |
| Musik prosedural | Lapisan musik generatif per dunia dengan Web Audio, tanpa berkas audio |
| Terjemahan | Bahasa Inggris dan bahasa daerah. Teks antarmuka perlu dikumpulkan ke satu tabel dulu. |
| Aksesibilitas | Pembaca layar untuk menu, kontras tinggi menyeluruh, kontrol satu tangan |
| Performa HP lama | Profil di perangkat Android kelas bawah, pengurangan draw call |
| iOS | Uji di iPhone asli: zoom, safe area, audio, pemasangan PWA |
| Uji dan dokumentasi | Uji tata letak tambahan, panduan kontributor bergambar |
